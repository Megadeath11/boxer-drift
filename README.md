# boxer-drift
Boxer Drift: low-poly gravel rally drifting in a '98 Legacy GT wagon. Download the latest .exe from Releases.

## Element Sandbox

This repo also contains [**Element Sandbox**](element-sandbox/), a 2D physics sandbox with 66 real materials (including gold, silver and platinum), heat, phase changes, combustion, explosions and wind, plus power-puzzle levels where you generate electricity from steam, heat and wind. It builds to a single portable `ElementSandbox.exe`; see [element-sandbox/README.md](element-sandbox/README.md).
