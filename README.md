# boxer-drift
Boxer Drift: low-poly gravel rally drifting in a '98 Legacy GT wagon. Download the latest .exe from Releases.

## Groundbreak (earthmoving sim)
A realistic digging & construction simulator lives in [`groundbreak/`](groundbreak/): excavator, dump truck and dozer on deformable layered soil. Run `node groundbreak/serve.js` and open http://localhost:8080. See [groundbreak/README.md](groundbreak/README.md).
